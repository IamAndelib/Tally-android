# German (de)

**Status: draft.** Written for Tally 1.4.2 without a native speaker; it awaits a native speaker's review (the
notes at the end list what to check first).

## Tone and address

Tally speaks to the user with the informal “du” (lower case, as the Duden allows), the way everyday German apps such
as banking, messaging and to-do apps do today. A pocket notebook for money is personal and casual; “Sie” would feel
stiff and add length. Labels are short and plain; buttons use the infinitive (“Speichern”, “Umbuchen”), messages use
full sentences with “du”. German quotes are „…“, the apostrophe ’, the dash – (en dash with spaces), the ellipsis is
written with a space before it (“Wird gesichert …”).

## Notes for reviewers

- **Loan direction.** German “leihen” means both lend and borrow, so Tally always uses “verleihen / verliehen (an)”
  for money the user gave and “sich leihen / geliehen (von)” for money the user received. Nouns: “Darlehen (an …)”
  for a lending, “Schuld (bei …)” for a loan. Please check that this pair reads naturally; “Darlehen” alone does not
  show a direction, so it is always paired with “an” where a name is shown.
- **Home buttons** “Borrow” / “Lend” are “Schuld” / “Verleihen”, matching “Schuld erfassen” / “Schuld speichern” in
  the borrow sheet; the section on Liabilities is “Schulden”.
- **Transfer** is “Umbuchung”, not “Überweisung” (which suggests paying someone else). Some apps say “Übertrag”.
- **Asset** is “Sachwert” (gold, a laptop); the tab is “Vermögen” and Liabilities is “Schulden” to stay short.
- **Owed to you** (heading on the Vermögen tab) is the colloquial “Bekommst du noch”.
- **Theme “Phone”** is “System”, the word German Android itself uses.
- **“Balances confirmed”** (after confirming the morning balance check) is “Kontostände bestätigt”.
- **Categories:** “Eating out” is “Essen gehen”, “Study” is “Bildung”, “Fun” is “Freizeit”, “Transport” is
  “Verkehr”, “Mobile wallet” is “E-Wallet”.
- **Permissions** use Android’s own German names (“Wecker und Erinnerungen”).
