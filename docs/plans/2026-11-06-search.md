# Search inside History — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Search becomes a mode of History, opened from every tab: typed words, suggestions that turn into History
filters (payee, category, account, person, kind, period, amount), marked matches, a clear nothing-found, and recent
searches kept on this phone only.

**Architecture:** `js/search.js` is rewritten as History's search mode. It keeps today's matching helpers (`srTerms`,
`srHit`, `oneTypo`, `srNum`, `srTexts`, `srEntryHit`) and adds the mode (`openFind()`, `findBack()`), the suggestions,
the marks and recent searches. History's filter (`HF` in `js/history.js`) gains the words (`q`), a payee (`pay`) and an
amount (`amt`), so the list, chips, counts, the Filters sheet and Clear all handle them as they handle every filter. The
old Search screen and its Week / Month / Year page are deleted. Recent searches live in the native shell
(`MainActivity.java`, a preferences file left out of Android's backup).

**Tech Stack:** Classic scripts in one global scope (WebView 87+), CSS in `rem`, Java for the shell, Playwright e2e
suites in `tests/e2e`.

**Spec:** `docs/specs/search.md` (approved 2026-11-06). Concepts: the Tally Search Concepts page (screens B1–B8).

## Global Constraints

- WebView 87: no `:has()`, no `:is()`, no `structuredClone`, no `color-mix()`.
- Every font size in `rem`; boxes holding text use `min-height`; words wrap, never cut or shrink (`22-layout.js`).
- Every visible text through `T()` / `TH()` with keys in `l10n/web/en.json` and all eight other languages, then
  `python3 tools/gen_i18n.py`; never run Prettier on `js/i18n/`. Until Task 6, new keys may carry English text in the
  other eight catalogues (suite 32 needs every key everywhere); Task 6 translates them.
- Touch targets 48dp; nothing by colour alone (a mark is also the matched text itself).
- Transfers, loan movements, fixes and fees never count as spent or received; currencies never added together.
- No change to saved data (no `migrate()` change): search state lives in memory; recent searches live in the shell.
- No network, no logging of what is typed.
- Commits end with only `Co-Authored-By: Claude <noreply@anthropic.com>`.

## Review Focus

1. **Typing fast on a big notebook**: 10,000 entries, every keystroke; the field keeps its caret and focus, the list
   follows after a short pause, nothing typed is lost (Task 2, Task 4 tests).
2. **Numbers in other formats**: a German phone types `1.250,50`, `50` vs `50,5`; `>50` and `<50`; an amount in a
   notebook with two currencies (Task 3 tests).
3. **Back from search** opened on each tab and on a filtered History; Android Back with a sheet open over search mode;
   rotation while searching (Task 2 tests).
4. **Words matching only a fee, only a hidden note, only a transfer's other side** (Task 1, Task 4 tests).
5. **Recent searches never leave the phone**: not in `S`, `save()`, backups, the shell's copy, CSV; gone after Erase
   everything (Task 5 tests).

### Task 1: Words, payee and amount as History filters

**Files:**
- Modify: `app/src/main/assets/js/history.js` (`histBlank`, `histMatch`, `histSet`, `histChip(s)`, `histDrop`,
  `histClear`), `app/src/main/assets/js/search.js` (keep the matching helpers; add the folded-text cache)
- Test: `tests/e2e/42-search.js` (new; add it to `tests/e2e/run.js`'s list if the runner needs one)

**Interfaces:**
- Produces: `histBlank()` → `{ acc, kind, cat, who, from, to, q: "", pay: "", amt: "" }`; `pay` is `"out:<folded
  name>"` or `"in:<folded name>"`; `amt` is `"eq:<lo>:<hi>"`, `"gt:<n>"` or `"lt:<n>"` (numbers as written by
  `String(n)`). `histMatch(t, f)` honours all three; a fee follows its host. `srFolded(t)` returns the entry's folded
  searchable texts, cached until the next `save()` (key the cache on `saveSeq`).
- Chips: `pay` → "Paid to X" / "Received from X" (X = the newest spelling of that payee), `amt` → "$50.00 to $50.99",
